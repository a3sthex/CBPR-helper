### P1 — структура backend (самая большая боль)

`server.py` — 20k строк монолитом, отработает любая правка долго из-за прокрутки. Размеченные секции уже есть (`# ---- каталог`, `# ---- правила`, `# ---- Session Recap`…), тесты грузят сервер через `importlib` — можно дробить безопасно:

1. Пилот: выделить `app/media.py` (media upload/get/delete — 3 роута, изолированы). Прогнать тесты.
2. Паттерн повторить по доменам: `auth`, `personas`, `contracts`, `feed`, `sessions+net`, `nightmarket`, `characters+sheet`, `admin`, `catalog`, `rules` (правила уже почти чистая секция 1610–2296).
3. Роутинг оставить в одном `ROUTES` — он хорошо читается таблицей.
4. Каждый шаг = отдельный коммит + прогон 260 тестов.

Риск: merge-конфликты с параллельными правками. Сейчас на ветке никого, кроме этой сессии, нет — окно удобное.
